# Hi, I'm Jiaxi Mao

Earth Sciences undergraduate at **University College London**. I apply machine learning to geoscience and environmental data, with a focus on **geothermal energy** and clean-energy screening.

## Projects

| Project | What it does | Result |
|---|---|---|
| [**gb-geothermal-temperature-ml**](https://github.com/JiaxiMao/gb-geothermal-temperature-ml) | Predicts subsurface temperature across Great Britain from the BGS Geothermal Catalogue, using spatial-block validation | MAE 2.64 °C, R² 0.945. Error is 29% lower than a linear geothermal-gradient baseline |
| [**london-pm25-ml**](https://github.com/JiaxiMao/london-pm25-ml) | Maps and predicts PM₂.₅ across London from traffic and green-cover data on a 500 m grid | XGBoost R² 0.60 on held-out 5 km blocks |
